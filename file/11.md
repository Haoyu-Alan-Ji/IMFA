## Joint Row-Sparse MFA: Design Decisions

### 1. What is Fitted Jointly

For observation $i$ assigned to cluster $g$,
$$x_i = \mu_g + \Lambda_g \eta_i + \epsilon_{ig}, \quad \eta_i \sim N(0, I_{q_g}), \quad \epsilon_{ig} \sim N(0, \Psi_g)$$

The sampler updates cluster labels, scores, means, diagonal uniquenesses, mixing proportions, loading magnitudes, and inclusion variables in one chain. No IMIFA estimate is used as a fixed loading matrix. An IMIFA-family MAP partition can be used only as an initial value through `z_init`.

The two loading priors are:
$$\lambda_{jkg} = s_{jkg} \gamma_{jkg}, \quad \gamma_{jkg} \sim \operatorname{Bernoulli}(\pi_g)$$

for `mode="default"`, and
$$\lambda_{jkg} = s_{jkg} \mathbb{I}(u_{jkg} > t_g)$$

for `mode="threshold"`. The Gaussian variables $s$, $u$, and the standardized threshold are updated with elliptical slice sampling. The binary $\gamma$'s have direct Bernoulli full-conditional updates.

---

### 2. From Element Sparsity to Row Selection

For feature $j$ in cluster $g$, define the row event:
$$r_{jg} = \mathbb{I}\left(\sum_{k=1}^{q_g} \gamma_{jkg} > 0\right)$$

The primary row posterior inclusion probability is therefore:
$$\operatorname{PIP}_{jg}^{\mathrm{row}} = P(r_{jg}=1 \mid X) = P\left(\bigcup_k \{\gamma_{jkg}=1\} \;\middle|\; X\right)$$

It is estimated by the fraction of retained MCMC draws in which at least one loading in that row is active. This definition remains meaningful under permutations and sign changes of loading columns, unlike the identity of an individual loading.

The default decision is the median-probability rule:
$$\widehat{r}_{jg} = \mathbb{I}\left(\operatorname{PIP}_{jg}^{\mathrm{row}} \ge 0.5\right)$$

Other summaries are returned, but they answer different questions:
* $\sum_k P(\gamma_{jkg}=1 \mid X)$ is the posterior expected number of active loadings in a row. It is not the probability that the row is active and can exceed one.
* $\max_k P(\gamma_{jkg}=1 \mid X)$ asks whether one stable factor-specific loading dominates. It can miss a row whose activity moves among rotated or permuted factors.
* $\mathbb{E}(\|\lambda_{jg}\|_2 \mid X)$ measures row signal strength. It requires a separately chosen practical-effect cutoff and is not an inclusion probability.

A credible interval for $\|\lambda_{jg}\|_2$ is awkward for an exact spike-and-slab because the posterior includes an atom at zero. Reporting the row PIP together with the conditional nonzero norm is clearer.

Thus, use the union-event row PIP for selection and report posterior mean row norm as an effect-size companion. **Do not use the sum of element PIPs as though it were a probability.**

### 3. One Threshold or One Threshold Per Cluster

The code supports both:
$$t_g, \quad g=1,\dots,G$$
with `threshold_scope="cluster"`, and
$$t_1 = \dots = t_G = t$$
with `threshold_scope="global"`.

A global threshold encodes a common element-level sparsity regime and pools information over all loading matrices. Cluster thresholds allow genuinely different element-level sparsity but add parameters and are less stable when each cluster has only 50 observations.

Equal row sparsity does not imply equal element sparsity when $q_g$ differs. If element gates were independent with activation probability $a_g$, then:
$$P(r_{jg}=1) = 1 - (1 - a_g)^{q_g}$$

Thus one common threshold gives different prior row-inclusion probabilities for $q_g=2$ and $q_g=3$. The present simulation has equal row support but unequal $q_g$, so neither scope is automatically correct: the global threshold pools more strongly, whereas cluster thresholds can compensate for the different numbers of opportunities for a row to become active. The code therefore treats the scope as an empirical comparison rather than silently choosing one.

The supplied test script fits both threshold scopes from the same initial partition and seed. Compare:
1. Clustering ARI;
2. Cluster-wise row-selection F1;
3. False positive count;
4. Posterior selected row count;
5. Between-chain stability over several simulation seeds.

If later simulations deliberately assign different sparsity rates to clusters, repeat this comparison; that setting may favor cluster-specific thresholds.

### 4. Literature Basis

* **Murphy, Viroli, and Gormley (2020)** formulate MFA as $\Sigma_g = \Lambda_g\Lambda_g^\top + \Psi_g$, discuss rotational non-identifiability, and give the IMIFA family and its Gibbs updates: [https://doi.org/10.1214/19-BA1179](https://doi.org/10.1214/19-BA1179)
* **Carvalho et al. (2008)** use spike-and-slab ideas for sparse loading matrices and interpret loading inclusion as sparse factor structure: [https://stat.duke.edu/~mwest/MWextrapubs/Carvalho2008.pdf](https://stat.duke.edu/~mwest/MWextrapubs/Carvalho2008.pdf)
* **Zhao et al. (2016)** distinguish element-wise and structured/group sparsity in factor loadings, emphasizing that element sparsity corresponds to feature-factor selection: [https://www.jmlr.org/papers/volume17/14-472/14-472.pdf](https://www.jmlr.org/papers/volume17/14-472/14-472.pdf)
* **Bhattacharya and Dunson (2011)** use global-local and cumulative shrinkage for sparse infinite factor models. Their continuous shrinkage does not create exact zeros, which is why it cannot itself supply the row inclusion event used here: [https://doi.org/10.1093/biomet/asr013](https://doi.org/10.1093/biomet/asr013)
* **Barbieri and Berger (2004)** define posterior inclusion probability and the $0.5$ median-probability decision rule. Their predictive optimality theorem is for normal linear-model settings, so the threshold is used here as a transparent decision convention, not claimed as a new MFA optimality theorem: [https://doi.org/10.1214/009053604000000238](https://doi.org/10.1214/009053604000000238)
* **Murray, Adams, and MacKay (2010)** establish elliptical slice sampling for latent variables with Gaussian priors: [https://proceedings.mlr.press/v9/murray10a.html](https://proceedings.mlr.press/v9/murray10a.html)

### 5. Practical Limitations

Element-wise loading indicators are not fully rotation invariant. Column permutation and sign ambiguity are harmless for the union-event row PIP, but a general orthogonal rotation can turn a sparse loading matrix into a dense one. The sparse prior chooses preferred orientations, yet factor-specific PIPs should still be interpreted more cautiously than row PIPs and recovered covariances.

The default simulation also makes cluster loading row norms equal to $2$, $3$, and $4$. This gives the clusters different marginal variances as well as different correlation structures. It is suitable for first verifying that the complete pipeline works, but it is not a correlation-only clustering experiment.
